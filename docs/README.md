Это спецификация и исполнимый план разработки, а не готовое приложение и не отчёт о выполненной разработке. Рабочая папка при исследовании была пустой, Git-репозиторий отсутствовал. Код, инфраструктура и платные API-вызовы не создавались и не запускались.

## Как использовать

Передать агенту весь каталог `docs`, а не только таблицу этапов. Первым прочитать спецификацию, затем контракты, план и release gates. Выполнять задачи по зависимостям. Промежуточные сборки — внутренние контрольные точки, не повод объявить продукт готовым.

Сформулированные здесь дополнительные требования — предлагаемые решения автора плана, а не якобы ранее согласованные пожелания пользователя. Особенно важны границы: одиночная игра; серверное хранение кампаний; три стартовых сценария; региональная модель карты; управляемое игровое время. Изменение этих решений требует обновления связанных контрактов и тестов до реализации. Пользователь отдельно подтвердил некоммерческое использование после консультации с юристом: CShapes включён в план с соблюдением CC BY-NC-SA 4.0.

Работа считается законченной только после закрытия всей обязательной матрицы и предъявления проверяемых артефактов. При отсутствии ключа, домена, инфраструктуры или лицензии соответствующая проверка остаётся заблокированной, а не отмечается успешно пройденной.
