## Implemented

- Dedicated db workspace package with node-postgres 8.23.0 and Drizzle 0.45.2; exact versions/lockfile.
- Versioned SQL migrations, serialized migration application and checksum verification.
- Owner-scoped campaign snapshots and history, canonical JSON SHA-256 with snapshot identity/version/hash checks.
- Commands with owner-scoped idempotency keys; changed payloads rejected. Cancellation requests permit stale revisions but validate target ownership/campaign.
- Job leases with fencing and expiration; checked again after writes before commit.
- Single-client transaction for revision CAS, event journal, touched territory/fact/relation projections, snapshot, job checkpoint and outbox.
- Outbox lease token, SKIP LOCKED claiming and fenced acknowledgment. Delivery remains at-least-once.
- No HTTP exposure of authoritative hidden world, no provider calls in transaction.
