# T04 — private sessions and BYOK vault (IN PROGRESS)

Date: 2026-09-06. Base: 3a2bde4. Branch: codex/implementation.

## Implemented and exercised

- CredentialCrypto: AES-256-GCM envelope encryption, random 32-byte data key, separate random 12-byte data/wrapping nonces, 16-byte tags. Authenticated context binds credential ID, owner, purpose, version and wrapping-key ID. Master keys are copied into private runtime fields. Temporary binary buffers are zeroed where practical; no guarantee of erasing immutable JS strings is made.
- Rotation rewraps authenticated data keys without rewriting the provider ciphertext; the old master key can be removed after successful rotation. Malformed/tampered/missing-key decryption fails with a generic code.
- CredentialVault: session plaintext stays in process memory, PostgreSQL stores reference/mask/instance metadata only. Inactivity expiry is eight hours. A different process instance cannot restore it. Persistent encrypted storage requires a configured master key and explicit API opt-in.
- Every get checks owner/revocation in PostgreSQL. Revoke removes ciphertext, clears the local session cache entry, cancels associated pending/running jobs and advances fencing. Jobs use a composite credential-owner FK.
- PostgreSQL session tokens are stored as SHA-256, not bearer plaintext. Eight-hour inactivity / seven-day absolute expiry; revoke/logout supported.
- Single-owner one-time bootstrap, returning-owner login with the externally configured bootstrap secret, rate-limited login routes.
- Cookie HttpOnly/SameSite=Lax/Path=/; Secure and __Host- prefix for HTTPS origins. HTTP is permitted only for an explicitly loopback private deployment (including listener address), not public deployment.
- Exact Origin checks for mutations; cookie session and constant-time CSRF checks for protected mutations; no-store responses.
- Credential API returns references/masks only. Explicit trustServer and persistentConsent gates. Errors omit raw user input; request logs omit bodies, headers and URL query strings.
- Real API entry point wires private mode, migrations, vault and sessions. Development is loopback-only; NODE_ENV=production does not default to unauthenticated development.
- Vite preserves /api/v1 paths; /api/health still proxies to /health. Root pnpm dev now builds API workspace dependencies before starting watchers, avoiding missing dist modules after a fresh installation.
