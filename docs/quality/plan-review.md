# Проверка пакета проектирования

Дата: 2026-09-05. Объект проверки — документация, не приложение.

## Что проверено

- Исходные пожелания прослежены до R01–R28, соответствующих T01–T36 и приёмочных сценариев.
- План содержит 36 пакетов работ и 180 незавершённых рабочих пунктов; приёмка — 18 сквозных сценариев и 10 групп gates.
- Исследованы оба пользовательских референса и официальные источники по Gemini, географии, лицензии CShapes и доступности.
- Оба заданных Gemini model ID подтверждены документацией; доступность конкретному ключу и практическое качество ещё не проверены.
- Учтено уточнение пользователя о некоммерческом использовании: CShapes включён, его условия сохранены отдельно от лицензирования кода/других assets.
- Статическая проверка Markdown: локальные файловые ссылки, парность code fences, последовательности T/R/A/Q, отсутствие маркеров незаполненного проектирования.
- Выполнен содержательный повторный проход границ истории, дипломатии, ролей, карты, сохранений, расходов и полноты API.

## Исправления по результатам повторного прохода

1. Контроль территории, претензии и признание получили разные операции; универсальный факт не заменяет эти изменения.
2. Ресурсные transfers и конфликты добавлены в типизированный контракт; модель не создаёт себе разрешение на расход.
3. Явно разделены exactly-once применение события и негарантированная однократность внешнего платного вызова.
4. Уточнён capped world planner: пакетная оценка фоновых стран не выдаётся за общую речь делегатов, due actors не пропускаются молча.
5. Заданы начальные context/output budgets по ролям и правило запрета потери точных обязательств при сжатии.
6. Добавлены API для изменения настроек кампании, heartbeat автохода, собственных preferences, досье, отчётов, поручений и целей.
7. Устаревшая revision не лишает игрока возможности отменить собственную генерацию.
8. Произвольная стартовая дата не заявляется достоверной без пакета/проверки; современные новости не overwrites историю партии.
9. Некоммерческий статус не трактуется как разрешение копировать любые ресурсы Windows/Pax.
10. Все критерии будущего приложения явно отделены от фактических результатов этого планирования.

## Что не выполнено и не утверждается

### Уточнение по замечанию пользователя о современной карте

Первоначальная проверка не выявила недостаточную конкретность формулировки «Natural Earth закреплённой актуальной версии». Наличие поставщика и общих acceptance criteria было ошибочно принято за достаточную детализацию. Проверка Markdown-ссылок этого недостатка не обнаруживает.

После замечания добавлены обязательные `modern-geography.md` и JSON manifest: конкретный release/commit, восемь файлов и blob hashes, algorithm геометрической сборки, инструменты, outputs, political patch contract, источники по назначению и критерии публикации. Согласованы T05/T07/T20, основная спецификация, control contract и release gate. Это уточнение плана, не утверждение, что современный игровой набор уже собран.

Код не реализован; библиотеки не установлены; миры 1945/1991/2026 не собраны и не фактчекнуты по каждой стране; тесты приложения, live Gemini calls, benchmarks, UI screenshots, пользовательские сессии и deployment не проводились. Эти действия входят в план и остаются обязательными.

Предложенные дополнительные решения (одиночный формат, три сценария, server-authoritative persistence, управляемое время) требуют согласия пользователя перед реализацией. Историческая экспертиза, лицензионные пограничные вопросы, доступ к API и реальное качество модели могут потребовать внешней проверки. План не гарантирует безошибочное приложение одним запуском агента; он задаёт проверяемый маршрут к полному релизу.
